# 使用指南

本指南面向使用 witden 的团队成员和管理员，介绍如何在话题中与 AI 角色协作、如何查看和接管虚拟电脑，以及如何配置角色、权限和审批。部署方法见[部署与配置](deployment.md)。

## 1. 界面概览

左侧边栏包含：

- **任务**：你发起或可以查看的全部任务。
- **审批**：等待你处理的审批请求。
- **话题**：你参与的话题，按最近活动排序；有新消息的话题加粗显示，私密话题带锁形图标。点击右侧的“+”新建话题。
- **角色**：你可以使用的角色。点击角色即打开与它的私信；有角色管理权限时，鼠标悬停会出现编辑按钮。
- **设置**：虚拟电脑、角色管理、模型、分配规则、通讯接入和系统管理，按你的权限显示。

侧边栏宽度可以拖动调整，双击分隔线恢复默认宽度。

## 2. 在话题中协作

### 2.1 创建话题

在“话题”旁点击“+”，填写：

- **标题**和**目标**：目标会作为角色在这个话题中工作的背景，建议写清楚要完成什么。
- **可见范围**：“私密”只有参与者可见；“团队内公开”所有成员都可以阅读。
- **邀请成员**和**邀请角色**：邀请角色需要你拥有该角色的“邀请角色进话题”权限。

话题的参与者（成员和角色）可以阅读话题的全部历史，包括自己加入之前的消息。

### 2.2 发送消息

- 输入框支持 Markdown：标题、列表、表格、任务列表、代码块和链接；` ```mermaid ` 代码块会显示为流程图。
- 点击“附件”可以从你自己的电脑上传文件；图片附件直接在消息中显示，点击可放大。
- 按 Enter 发送，Shift+Enter 换行。

你发送的消息显示在右侧，角色和其他成员的消息按发送者显示。

### 2.3 @ 角色和成员

在输入框中输入 @，从弹出的列表中选择角色或成员，才构成一次有效的 @。粘贴或手动输入的“@名称”只是普通文字，不会让角色开始工作。消息中只有有效的 @ 会高亮显示。

### 2.4 角色响应方式

每个群组话题都可以在顶部的“角色响应”开关中选择以下两种方式之一（鼠标悬停可以查看说明）。只有话题负责人可以切换，也可以在右侧栏“设置”中修改。

| 方式 | 说明 |
|---|---|
| 主动 @（默认） | 角色只在被 @ 时响应。 |
| 自动 | 没有 @ 任何角色的消息也可能交给角色处理。话题中只有一个角色时，它会查看每条消息并自行判断是否需要回复，例如成员之间闲聊时不回复。话题中有多个角色时，由管理员配置的调度模型决定交给哪些角色，可以是一个、多个或都不交。 |

在两种方式下，被 @ 的角色都会响应。私信中的角色总是回复你的消息。

如果话题设为“自动”且有多个角色，但管理员尚未配置调度模型，话题顶部会显示“未设置调度模型”，此时没有 @ 的消息不会交给任何角色。

### 2.5 查看角色的工作

- 角色接到工作后，消息区底部会显示它的状态：“正在思考”、正在使用的工具（例如“正在执行命令”），以及正在生成的回答。如果回答涉及当前话题中部分成员无权查看的资料，只显示状态而不显示内容。
- 右侧栏“任务”列出话题中的全部任务。对进行中的任务，你可以**暂停**、**补充要求**、**转交**给其他角色或**取消**；失败或已取消的任务可以**重试**。
- 点击任务标题可以查看每一步的执行记录和分配依据。

### 2.6 右侧栏

| 标签 | 内容 |
|---|---|
| 任务 | 话题中的任务及其控制操作。 |
| 审批 | 话题中等待处理的审批。 |
| 虚拟电脑 | 话题中角色所在的虚拟电脑，见第 3 节。 |
| 参与者 | 成员和角色列表，可以邀请或移除。 |
| 会话 | 每个角色在本话题中的会话记录（已交付结论的摘要）。 |
| 文件 | 话题中的全部文件，点击下载到你自己的电脑。 |
| 记忆 | 本话题的记忆，角色在这个话题中工作时会参考。 |
| 设置 | 标题、目标、可见范围、角色响应方式、角色之间自动讨论的轮次上限；归档、发布到外部频道和清理数据。 |

### 2.7 私信

点击侧边栏中的角色即可与它私信。私信是你与这个角色之间的私密对话，其中的资料不会被带到其他话题，除非你批准。

## 3. 虚拟电脑

### 3.1 在话题中查看

右侧栏“虚拟电脑”标签显示话题中角色所在的虚拟电脑。有多台时可以在顶部切换。顶部一行显示虚拟电脑名称、运行状态和当前操作者（空闲、AI 操作中或某位成员正在接管）。

- **桌面虚拟电脑**：显示只读的实时画面缩略图。鼠标悬停在缩略图上会出现放大图标，点击即可放大。
- **命令行虚拟电脑**：拥有“接管虚拟电脑”权限的成员可以在这里直接执行命令。

点击“放大”后，虚拟电脑画面占据整个话题区域，对话收起为右下角的“对话”按钮，有新消息时按钮上会显示数量。点击按钮打开对话窗口，拖动窗口标题栏可以移动它，拖动边缘或角可以调整大小；对话按钮本身也可以拖动。点击“还原”恢复正常布局。

### 3.2 接管与交还

需要亲自操作时（例如完成登录或验证码），拥有“接管虚拟电脑”权限的成员可以在放大后的画面中点击状态栏上的“接管并操作”：

- 接管后，你的鼠标和键盘操作会发送到这台虚拟电脑，不会影响你自己的电脑；这台虚拟电脑上所有角色的 AI 工作暂停。
- 如果当时有 AI 工作正在进行，会先提示将暂停几项工作，确认后接管。
- 完成后点击“交还控制”，AI 工作随即恢复。

为避免 AI 工作长时间停滞，出现以下情况时系统会自动交还控制：

- 离开当前页面或视图，例如切换到其他页面、切换右侧栏标签、还原布局或关闭页面；
- 浏览器标签页在后台停留超过 30 秒；
- 超过 5 分钟没有鼠标或键盘操作；
- 浏览器异常关闭或网络中断时，服务器在约 3 分钟后自动交还。

### 3.3 虚拟电脑页面

在“设置 → 虚拟电脑”中可以查看和管理全部虚拟电脑。每台虚拟电脑的页面包括：

| 标签 | 内容 |
|---|---|
| 概览 | 状态、资源占用、分配的角色、共享范围；启动、停止、重启、重置、删除等操作。 |
| 屏幕 | 实时画面（桌面虚拟电脑）与截图。 |
| 控制台 | 以虚拟电脑内的普通用户身份执行命令，所有命令记录审计。 |
| 会话 | 角色打开的终端和浏览器会话。 |
| 模型访问 | 允许虚拟电脑中的程序使用平台的模型，见 3.4。 |
| 备份与复制 | 备份、恢复，以及复制为新的虚拟电脑（默认不复制账号凭据）。 |
| 任务 | 在这台虚拟电脑上执行过的任务。 |

同一台虚拟电脑上的角色共享文件、已安装的软件和登录状态。需要互相保密的工作，请分配到不同的虚拟电脑。

### 3.4 虚拟电脑内的模型访问

在“模型访问”中开启后，虚拟电脑中的程序（例如成员或角色安装的其他工具）可以通过虚拟电脑内部的地址，使用平台为这台虚拟电脑签发的密钥调用平台中的模型。页面会显示 OpenAI 兼容和 Anthropic 两种接口的地址，这些地址只在这台虚拟电脑内部有效。真实的服务地址和密钥不会进入虚拟电脑；签发的密钥可以随时更换，离开这台虚拟电脑无法使用。只能选择你自己有权使用的模型，用量按虚拟电脑统计。

## 4. 角色

在“设置 → 角色管理”中创建和编辑角色（需要“管理角色”权限）。

| 部分 | 内容 |
|---|---|
| 身份 | 名称、@ 名称（在话题中用于 @）、头像、徽章颜色、职责说明。 |
| 工作方式 | 提示词：职责、工作规则和沟通方式。权限由系统执行，不依赖提示词。 |
| 模型 | 角色使用的模型、模型能力和模型参数。 |
| 虚拟电脑 | 角色工作所在的虚拟电脑。未分配时角色只能对话。 |
| 权限 | 工具权限、可以联系和委托的角色、可读取的知识空间。 |
| 限额 | 单个任务的最大步数和 token 上限、每日 token 上限。 |

### 4.1 工具权限

工具按类别列出，每一类可以设为：

- **始终允许**：直接使用；
- **询问**：每次使用前需要有审批权限的成员批准，角色不能批准自己的请求；
- **禁用**：角色不能使用。

展开某一类可以单独要求其中的某个工具“询问”。

新建角色的默认权限为：在自己虚拟电脑里的操作（执行命令、终端、文件、桌面、浏览器，以及把虚拟电脑中的文件分享到话题）始终允许；联系或委托其他角色、使用平台记忆、读取其他话题需要询问。已有角色可以在权限列表底部点击“恢复默认”套用默认值。

无论权限如何设置，向话题输出内容时都会检查资料的可见范围，见第 5 节。

### 4.2 修改角色的影响

角色正在进行的任务继续使用开始时的配置，新任务使用新配置。更换角色所在的虚拟电脑不会迁移文件、已安装的软件和登录状态；固定在原虚拟电脑上的任务需要等待完成或取消。

## 5. 审批与资料保护

以下情况会产生审批，出现在“审批”页面和话题右侧栏中：

- **工具审批**：角色使用设为“询问”的工具。审批人由“审批”权限决定，并且必须能查看请求涉及的全部资料。
- **资料公开审批**：角色要在话题中发布的内容用到了部分参与者无权查看的资料（例如来自某位成员私信的信息）。这类内容会先暂扣，由资料的所有者决定是否公开；一次批准只放行一条消息。

## 6. 成员与授权

在“设置 → 系统管理 → 授权”中为成员授予权限。所有权限默认不授予，可以授予全局，也可以限定到具体的角色、虚拟电脑、话题、模型、知识空间或通讯接入。

| 权限 | 作用 |
|---|---|
| 创建话题 | 新建群组话题。 |
| 使用角色 | 向角色交代工作、与角色私信。 |
| 邀请角色进话题 | 把角色加入话题。 |
| 管理角色 | 创建、编辑、停用角色。 |
| 观察虚拟电脑 / 接管虚拟电脑 / 管理虚拟电脑 | 查看实时画面 / 接管和使用控制台 / 创建和管理虚拟电脑。 |
| 管理模板 | 管理虚拟电脑模板。 |
| 管理模型与密钥 | 管理模型服务商、模型和话题调度模型。 |
| 使用模型配置 | 把某个模型用于角色，或开放给虚拟电脑内的程序。 |
| 下载话题文件到自己的电脑 | 下载话题中的文件。 |
| 管理分配规则 | 配置请求由哪些角色处理。 |
| 管理通讯接入 | 配置 Slack、飞书连接。 |
| 发布话题到外部频道 | 把话题同步到外部频道。 |
| 审批 | 批准或拒绝工具审批。 |
| 查看审计与用量 | 查看审计记录和模型用量。 |
| 管理成员与授权 | 管理成员账号和授权。 |
| 读取 / 编辑知识空间 | 使用或维护团队知识。 |
| 紧急停止 | 立即暂停 AI 工作。 |

管理员可以归档、移除参与者和清理私密话题，但不能阅读自己没有参与的私密话题和私信，也不能扩大它们的可见范围。

## 7. 紧急停止

在“设置 → 系统管理 → 紧急停止”中可以立即暂停全部 AI 执行，或只暂停某个角色、某台虚拟电脑、某个通讯接入、某个话题或某项任务（包括它委托出去的工作）。停止期间做出的审批决定会被记录，解除后才执行。解除后，被暂停的任务可以继续。

## 8. 话题调度

“设置 → 系统管理 → 话题调度”用于选择调度模型（需要“管理模型与密钥”权限）。当话题设为“自动”且有多个角色时，调度模型根据角色的名称和职责说明，判断没有 @ 角色的消息应交给哪些角色。调度的 token 用量计入所选模型。

调度模型必须是 **System 1 模型**，即响应快、不先进行长时间思考的模型。配置方法：

1. 在“设置 → 模型”中添加模型时，勾选“标记为 System 1”；已有的模型可以点击“编辑”后开启。
2. 默认会先思考的推理模型需要关闭思考。编辑模型时，可以从“为推理模型关闭思考”列表中选择对应的服务类型，自动插入所需参数：Qwen3 等开源模型（vLLM、SGLang 部署）、通义千问（阿里云百炼兼容接口）、OpenAI GPT-5 系列。DeepSeek 请使用 `deepseek-chat`（`deepseek-reasoner` 无法关闭思考）；Anthropic 模型默认不开启思考，无需设置。
3. 点击“检测能力”。模型列表会显示响应时间；如果检测时模型仍先输出了思考过程，会提示“会先思考”，此时应调整参数或换用其他模型。
4. 回到“话题调度”，从列表中选择该模型并保存。列表只显示标记为 System 1 的模型。

调度模型被停用、服务不可用或取消了 System 1 标记时，没有 @ 的消息不会交给角色，话题中会给出提示。

## 9. 个人设置

点击侧边栏左下角你的名字进入个人页面，可以查看账号信息、自己拥有的权限，以及角色为你保存的私密记忆（可以删除）。
